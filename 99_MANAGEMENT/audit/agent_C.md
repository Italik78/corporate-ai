## Работи (ПОТВЪРДЕНО)
- ING structured-query: 401 без токен; document_id+source_file заедно -> 422 DOCUMENT_REFERENCE_AMBIGUOUS; несъществуващо -> 404; префикс «От файла …» -> 404 (fail-closed); непознат оператор (regex) -> 422 от pydantic; непозната колона -> 422 UNKNOWN_COLUMN; .xlsx -> 422 UNSUPPORTED_STRUCTURED_FORMAT; само CURRENT (403 иначе); ACL по scope+classification+project след resolve (main.py:231-247); eq/contains/дата филтри и total_matches коректни (Прекратен=2, Край на действие 2025 = 37, общо 180).
- Row provenance: sheet, sheet_index, row_index, content_hash, document_id, version.
- Dedup по SHA-256 (не по име), unique index (hash,project,scope); PG partial unique CURRENT per document; canonical storage + integrity проверка; идемпотентен replay на INGESTING; хардънат контейнер (read_only, cap_drop ALL, no-new-privileges); admin/recovery endpoints с отделен токен и compare_digest; Paperless webhook secret; poller: durable volume, atomic state replace.
- Brain валидация: source_file XOR document_id/version (brain.py:100-104), STRUCTURED_QUERY само при CORPORATE policy.
- advisory lock по document_id в register_version.
